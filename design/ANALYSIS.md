# Анализ дизайна NeuralAd Engine → AI Context-Buyer Platform

## Вердикт

**Визуальная система — да, подходит** (с оговорками).  
**Информационная архитектура и демо-контент — нет, 1:1 не переносить.**

Stitch-макеты — хороший **скин** (тёмный enterprise shell, densе таблицы, KPI, stepper).  
Продуктовая логика BotKontext другая: пайплайн контекстолога (бриф → анализ → семантика/план → объявления → кабинет), а не multi-network bandit SaaS.

---

## Что берём

| Элемент дизайна | Почему ок |
|-----------------|-----------|
| Sidebar + sticky top bar | Уже есть в `AppShell`, усилим визуально |
| Hairline borders, densе table | Хорошо для портфеля / аналитики / журнала |
| KPI cards + sparkline | Аналитика, расходы LLM, ROAS/CPL |
| Multi-step wizard | Пайплайн: Бриф → Анализ → План → Объявления → Кампания |
| Dark tokens + Geist/Inter/Mono | Совпадает с Geist в проекте; сейчас light zinc — можно dark mode |
| Status pills (active / optimizing / paused) | Статусы кампаний и задач агентов |

## Что не берём / меняем

| В макете | У нас |
|----------|--------|
| NeuralAd Engine, Dirichlet, Monte Carlo | AI Context-Buyer / white-label branding |
| Campaigns, Audiences, Creative AI, Meta/TikTok | Портфель + вкладки проекта (см. ниже) |
| Create Campaign / Deploy Variant | «Прогнать пайплайн», «Запустить кампанию» (только из UI) |
| Autonomous AI Feed (budget rebalance) | Рекомендации + автопилот (с явным approve) |
| Creative AI Engine (diffusion / Claude copy) | Объявления (копирайтинг) + Медиа (мок/генерация) |
| English SaaS copy | Русский UI |
| Purple glow / neon overkill | Чуть сдержаннее (правила: без «AI purple glow» как доминанты) |

## Маппинг экранов

### 01 Dashboard → Портфель + обзор проекта / Аналитика

- KPI: расход, CPL/ROAS, конверсии, активные кампании  
- Таблица: проекты / кампании (Яндекс Директ · Google Ads)  
- CTA: **Новый проект**, **Обновить статистику**, **Подключить кабинет**

### 02 Wizard → Пайплайн кампании

| Step в макете | Наш шаг |
|---------------|---------|
| 01 Objective & Channels | Бриф + платформа |
| 02 Bandit Budget | Бюджет / CPL в брифе |
| 03 Creative AI & Variants | Объявления + семантика |
| 04 Safeguards & Review | Черновик → **Запустить кампанию** (подтверждение) |

CTA: **Прогнать пайплайн до черновика**, **Отменить и доработать**, **Запустить кампанию**

### 03 Creative AI → Объявления (+ медиа)

- Матрица вариантов объявлений → текущие creatives  
- CTA: **Сгенерировать объявления**, **Сохранить правки**, **Перезапустить**  
- Visual assets → вкладка медиа / генерация (если включена)

## Ключевые кнопки продукта (подставить в UI)

| Контекст | Primary | Secondary |
|----------|---------|-----------|
| Пайплайн | Прогнать пайплайн до черновика | Отменить и доработать |
| Кабинет | Подключить / Переподключить Яндекс Директ / Google Ads | Обновить токен · Отключить |
| Анализ | Запустить / Перезапустить анализ | Добавить свои слова |
| План / семантика | Собрать семантику / Утвердить план | Экспорт |
| Объявления | Сгенерировать объявления | Сохранить |
| Кампания | Запустить кампанию | Редактировать черновик |
| Аналитика | Обновить статистику | Период 7/30/90 |
| Рекомендации | Принять · Применить | Отклонить |
| Автопилот | Включить автопилот | Выключить |

Правило продукта: **нет автопубликации без подтверждения** — primary CTA на запуске всегда явный.
