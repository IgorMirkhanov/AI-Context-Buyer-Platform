# AI Context-Buyer Platform — пакет проектной документации

Мультиагентная SaaS-платформа, которая выполняет полный цикл работы контекстолога
(Яндекс Директ + Google Ads) для множества клиентских проектов одновременно:
от брифа и семантики до запуска кампаний, ведения и отчётности.

## Как пользоваться этим пакетом в Cursor

1. Склонируйте/создайте пустой репозиторий, положите папку `docs/` с этими файлами в корень.
2. Добавьте `.cursorrules` (файл 08) в корень репозитория — это даст Cursor Agent
   контекст о проекте на каждый промпт.
3. Этапы **0–17 уже реализованы**. `07_ROADMAP_MVP.md` — факт-лог, не план
   «сделай этап N заново». Новый код — только по явной задаче.
4. Готовность к живому клиенту: чеклист в `10_RISKS_AND_OPEN_QUESTIONS.md`,
   раздел 7.

## Ключевые решения, зафиксированные в пакете

- **Мультиклиентская архитектура**: один бот подключается к N аккаунтам через OAuth2,
  каждый проект — изолированная запись с собственными токенами, брифом и данными.
- **Мультиагентный подход**: оркестратор + специализированные агенты (семантика,
  копирайтинг, валидация, сборка кампаний, оптимизация, отчётность), а не один
  универсальный промпт.
- **Приоритет платформ**: Яндекс Директ и Google Ads — два адаптера
  `AdPlatformConnector` (`04_API_INTEGRATIONS.md`). CRM — `AttributionConnector`,
  картинки — `MediaGenerationConnector`.
- **Human-in-the-loop:** публикация только из UI (paused). Автопилот — opt-in
  после порога, без создания кампаний.
- **Биллинг не требуется** для внутреннего продукта (`organizations.plan` —
  колонка без логики тарифов; не открытый пробел релиза).
