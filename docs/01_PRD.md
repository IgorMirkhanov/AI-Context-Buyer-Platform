# PRD — AI Context-Buyer Platform

## 1. Проблема

Ведение контекстной рекламы (Яндекс Директ, Google Ads) — трудоёмкий ручной процесс:
сбор семантики, написание объявлений, настройка кампаний, ежедневная чистка трафика,
отчётность. Агентства и фрилансеры-контекстологи тратят на это десятки часов на
каждый проект, а качество сильно зависит от квалификации конкретного человека.

## 2. Продукт

SaaS-платформа с ИИ-агентами, которая берёт на себя весь цикл работы контекстолога
для множества проектов одновременно. Клиент (агентство, маркетолог, владелец бизнеса)
подключает рекламный кабинет через OAuth, заполняет бриф — платформа сама собирает
семантику, готовит объявления, настраивает и ведёт кампании, показывает отчётность.

## 3. Целевые пользователи (персоны)

1. **Агентство контекстной рекламы** — ведёт 20-200 клиентских аккаунтов,
   хочет автоматизировать рутину и масштабироваться без пропорционального роста штата.
2. **Контекстолог-фрилансер** — хочет вести больше проектов силами одного человека.
3. **Владелец малого/среднего бизнеса** — хочет получить рекламу «под ключ»
   без найма отдельного специалиста.

Для MVP приоритет — Персона 1 и 2 (B2B, готовы к настройке через API/бриф,
терпимы к интерфейсу, важна экономика на объёме).

## 4. Скоуп MVP (что делаем в первую очередь)

Включено:
- Онбординг проекта: бриф (JSON/форма) + подключение одного рекламного кабинета
  (Яндекс Директ **или** Google Ads — выбрать один для первого релиза).
- Агент семантики: сбор масок → расширение → минус-слова → кластеризация.
- Агент копирайтинга: заголовки, тексты объявлений, быстрые ссылки по кластерам.
- Агент валидации: проверка лимитов платформы, кросс-минусация, базовые
  compliance-проверки (запрещённые слова, длина текстов).
- Сборка черновика кампании (структура: кампании → группы → объявления → ключи)
  с выгрузкой в формате, готовом к загрузке в кабинет (или прямой push через API
  в статусе "черновик"/"на паузе").
- Ручное подтверждение запуска человеком.
- Базовый дашборд: список проектов, статус, ключевые метрики (после запуска).

Исходный скоуп MVP (этапы 0–5 в старом плане) — онбординг, семантика,
объявления, валидация, черновик, запуск на паузе, отчёт.

**Факт после этапов 0–17** (см. `07_ROADMAP_MVP.md`): в коде также есть
второй коннектор (Google Ads), Optimization Agent, CRM-атрибуция, media-превью,
white-label, автопилот (opt-in, без createCampaign), оркестратор + очередь,
ops-алерты, ротация OAuth, audit-журнал, сводка LLM. **Нет:** биллинга
(`organizations.plan` не используется), живого прогона песочницы Яндекса
человеком. Чеклист — `10_RISKS_AND_OPEN_QUESTIONS.md`, раздел 7.

По-прежнему не делаем:
- автопубликацию кампаний без кнопки в UI;
- Performance Max / мастер кампаний как отдельный режим.

## 5. Пользовательский путь (happy path, MVP)

1. Пользователь регистрируется, создаёт новый проект.
2. Подключает рекламный кабинет через OAuth ("Подключить Яндекс Директ").
3. Заполняет бриф проекта (см. `09_ONBOARDING_BRIEF_TEMPLATE.md`): URL, гео, бюджет,
   УТП, ЦА, стоп-слова.
4. Платформа запускает пайплайн агентов, показывает прогресс по этапам
   (семантика → объявления → структура кампании).
5. Пользователь видит черновик кампании: семантическое ядро с кластерами,
   объявления по группам, минус-слова, настройки таргетинга и бюджета.
6. Пользователь редактирует/утверждает элементы точечно (не всё целиком).
7. Пользователь нажимает "Запустить" — кампания создаётся в кабинете в статусе,
   заданном пользователем (черновик/активна).
8. После запуска — регулярный сбор статистики и уведомления о нужных действиях
   (не автоматическая правка, а рекомендация + кнопка "применить").

## 6. Метрики успеха

- Время от заполнения брифа до готового черновика кампании (цель MVP: < 30 минут
  для проекта среднего размера, ~200-500 ключевых слов).
- Доля предложений агента, принятых пользователем без правок (прокси-метрика
  качества генерации).
- Количество одновременно обслуживаемых проектов на одного пользователя платформы.
- Retention: доля проектов, где пользователь возвращается на 2-ю неделю ведения.

## 7. Ограничения и допущения

- Работаем в рамках официальных API (Яндекс Директ API v5, Google Ads API),
  без обхода лимитов и антифрод-механизмов платформ.
- Токены доступа хранятся зашифрованными, per-project, с поддержкой отзыва доступа.
- Автопилот есть как **opt-in после порога качества рекомендаций**; новые
  кампании он не создаёт. Публикация — только подтверждение в UI.
